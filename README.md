# Weapon Detection 🔫

A real-time computer vision project for detecting weapons using YOLO and OpenCV.

## Technologies

- Python
- YOLO
- OpenCV
- Ultralytics

## Features

- Real-time camera detection
- Object detection using YOLO
- Confidence-based detection
- Live bounding boxes
